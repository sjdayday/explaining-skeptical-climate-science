# ESDD open-review record (2013) — the adversarial exchange

The first version of Benestad et al., titled "Agnotology: learning from
mistakes" (Earth Syst. Dynam. Discuss. 4:451–505, doi:10.5194/esdd-4-451-2013,
posted 03 May 2013), went through public interactive review. The revision was
not accepted (Final Editor decision C400, Matthew Huber, 03 Sep 2013); the
expanded work later appeared in Theor. Appl. Climatol. (2016). All comments
remain openly archived (CC BY 3.0) at:
https://esd.copernicus.org/preprints/esd-2013-12/
